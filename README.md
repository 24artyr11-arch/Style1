# Гардероб — Telegram-бот

## Что реализовано

- Личные чаты с ботом доступны всем пользователям.
- Несколько фотографий одним альбомом: каждая обрабатывается отдельно, по очереди.
- Одна вещь на фото; пара обуви считается одной вещью.
- ИИ распознаёт категорию и признаки вещи. Категорию можно исправить кнопкой.
- Гардероб с просмотром фото, страницами и удалением; при навигации старое сообщение очищается, где возможно есть кнопка «Назад».
- Выбор температуры, погоды, повода, стиля и цветов кнопками.
- От одного до трёх разных комплектов с фотографиями исходных вещей и пояснениями — сколько позволяет гардероб.
- Замена любой вещи вручную на другую вещь той же категории, с пересборкой коллажа.
- Последние три образа доступны после перезапуска; хранится до 30 образов на пользователя.
- Нет профиля, подписок и платежей. Есть согласие на обработку фото и удаление всех данных.

Коллажи собирает Pillow, поэтому GPT Image не нужен и генерация картинок не оплачивается.
GPT анализирует каждую новую фотографию один раз и подбирает комплекты по сохранённым описаниям.
Категория после ручного исправления имеет приоритет перед описанием ИИ.

## Быстрый запуск

Понадобится компьютер/сервер с Docker Compose, исходящим HTTPS-доступом к Telegram и OpenAI,
токен уже созданного бота и ключ OpenAI с доступом к выбранной модели и оплаченным API.
Домен и открытые входящие порты не нужны: используется long polling.

1. Скопируйте `.env.example` в `.env`.
2. Заполните `TELEGRAM_BOT_TOKEN` и `OPENAI_API_KEY`.
3. Если бот уже запускался и в нём есть гардеробы, выполните `docker volume ls` и укажите в `WARDROBE_VOLUME_NAME` имя уже существующего volume с базой (при стандартном запуске это `style1_wardrobe_data`). Так новая версия продолжит использовать прежнюю базу.
4. Выполните:

```bash
docker compose up -d --build
docker compose logs --tail=50 bot
```

После изменения `.env` или пересборки:

```bash
docker compose up -d --build --force-recreate
```

Гардеробы сохраняются в именованном Docker volume и не удаляются при `restart`, `up --build` или пересоздании контейнера. Не используйте `docker compose down -v` и не удаляйте volume вручную: флаг `-v` удаляет базу с гардеробами.

Откройте бота, отправьте `/start`, примите условия и загрузите фотографии.
Не запускайте параллельно другую программу с этим же Telegram-токеном.
При активном webhook программа останавливается, не изменяя существующую интеграцию.
Сначала отключите старый сервис, если он был подключён.

## Первая проверка

Добавьте минимум три разных верха, один низ и одну пару обуви для выбранной погоды.
Это позволит составить три различных набора. Нажмите «Подобрать образы» и ответьте на пять вопросов.
Проверьте категории, изображения и пояснения. Нажмите «Заменить» под одним комплектом,
выберите другой верх: бот пришлёт обновлённый коллаж. Остальные комплекты не изменятся.

## Ограничения первой версии

- Один процесс, последовательная обработка: во время запроса к ИИ остальные задачи ждут.
  Это не архитектура для высокой публичной нагрузки: при большом числе пользователей потребуется масштабирование.
- Параметры относятся к текущему подбору; отдельного пользовательского профиля нет.
- Нет удаления фона. На коллаже сохраняется фон загруженных фотографий.
- Фото нормализуются в JPEG до 1280×1280, без EXIF. Telegram также сжимает фото.
- До 200 вещей на пользователя. Загружать нужно как фотографии, не как документы.
- Полный образ включает обувь и верх+низ либо платье/комбинезон. Бот выдаёт от одного до трёх
  подходящих наборов и сообщает о нехватке только если нельзя составить ни одного. Он не подставляет
  вещи, отсутствующие в гардеробе.
- Замены выбирает пользователь из той же категории; ИИ не проверяет повторно совместимость
  ручной замены с погодой. В интерфейсе об этом есть напоминание.
- После исправления категории или удаления вещи старые образы сбрасываются.
- Качество подбора и распознавания требует проверки на реальных фото; возможны ошибки ИИ.
- Лимита расходов в долларах в коде нет. Контролируйте Usage в OpenAI; публичный доступ
  не заменяет финансовый лимит. Автоматических повторов платных запросов нет.
- Update отмечается обработанным до выполнения: аварийная остановка может потребовать
  повторной отправки фото/запуска подбора пользователем, зато не запускает платный запрос повторно автоматически.
- Нет автоматических резервных копий. Для ручной копии остановите контейнер и сохраните
  файл `/data/wardrobe.sqlite3`; срок хранения и удаление резервных копий — ответственность владельца.

## Данные и безопасность

Фото хранятся BLOB-ами в SQLite `/data/wardrobe.sqlite3` на постоянном Docker volume с закреплённым именем. Перезапуск и пересоздание контейнера используют ту же базу. Удаление всех данных удаляет
фотографии, описания, образы, ответы и согласие пользователя и очищает свободные страницы базы.
Изоляция выполняется по Telegram ID во всех запросах, включая callback-кнопки.
Секреты и фотографии в журнал не выводятся, сохраняются только количества токенов и типы ошибок.
`.env` не входит в Docker image и не должен попадать в git или переписку.

Удаление на сервере бота не удаляет сообщения и исходные фото из Telegram или данные,
которые провайдер обязан/может хранить по своим правилам. Пользователь получает это пояснение
перед первой загрузкой. В OpenAI запросах установлено `store=false`; это не обещание нулевого
хранения данных провайдером. База не зашифрована: ограничьте доступ к серверу и диску.

## Разработка и проверки без ключей

Python 3.12+, Pillow; шрифт DejaVu Sans нужен для кириллицы в коллажах.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Для запуска без Docker установите переменные окружения из `.env` средствами своей системы
и `DATA_DIR=./data`, затем выполните `python bot.py`. Сам скрипт `.env` не читает, это делает Compose.

Тесты используют подставные Telegram/OpenAI и не вызывают платных сервисов.
Живая интеграция и сборка Docker должны быть проверены владельцем после добавления ключей.

## Структура

- `bot.py` — Telegram, OpenAI Responses API, меню, опрос и polling.
- `core.py` — SQLite, проверки комплектов, нормализация фото, коллажи.
- `tests/test_bot.py` — сценарные проверки без сети.

Документация: https://developers.openai.com/api/docs/guides/structured-outputs
и https://core.telegram.org/bots/api
